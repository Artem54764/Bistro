# Bistro

Zamówienia, menu, mapa tras i tracker dostaw dla Trzcina Bistro (Kielce). Next.js.

Potrzebny Node.js 18.18 lub nowszy (`node -v`).

    npm install
    npm run dev

Otwórz http://localhost:3000

- **Nowe zamówienie** — formularz z podpowiedziami ulic, paragon do druku
- **Tracker** — do wysłania / w drodze / dostarczone, kierowcy
- **Mapa** — lista ulic z zamówień, trasy dla kierowców (OpenStreetMap + OSRM)
- **Menu** — menu dnia i stałe menu

Dane są zapisywane w przeglądarce (localStorage).
